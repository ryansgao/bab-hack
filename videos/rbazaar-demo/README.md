# rBazaar — B@B Hacks 2.0 demo video

A ~1:54, 1920×1080 HyperFrames composition that pitches rBazaar, demos it, explains the AUSD/x402 and BNB Chain internals, and covers what broke.

| Section | Frames | Time |
| --- | --- | --- |
| What rBazaar is | 01–05 | 0:00–0:29 |
| Live demo (keeps explaining) | 06–09 | 0:29–1:00 |
| Technical: x402 + AUSD, BNB policy contract, numbers | 10–12 | 1:00–1:29 |
| What broke and how we fixed it | 13–14 | 1:29–1:49 |
| End card | 15 | 1:49–1:54 |

## Files

- `STORYBOARD.md` — frame-by-frame plan (VO line, timing, shot sequence, assets).
- `SCRIPT.md` — the narration. You can read it aloud yourselves (see below).
- `frame.md` — design tokens (cream canvas, sage, Instrument Serif + Inter, glass cards), taken from the app.
- `compositions/frames/NN-*.html` — one sub-composition per frame. `index.html` assembles them with voice, music and SFX.
- `assets/` — real app screenshots and screen captures, the logo, fonts, `voice/`, `bgm/`, `sfx/`.

## Commands

```sh
cd videos/rbazaar-demo
npx hyperframes preview --background   # Studio preview (stop with: npx hyperframes preview --stop)
npx hyperframes check                  # lint + runtime + layout checks
npx hyperframes render --quality high --output renders/video.mp4
```

## Replace the AI voice with your own

The narration is local Kokoro TTS (`am_michael`, 1.1×). To use a teammate's voice:

1. Record each line in `SCRIPT.md` as `assets/voice/01.wav` … `15.wav`. Keep each take about as long as the current file, or shorter.
2. Add about 0.4 s of silence to the end of each take (frame 6: 1.6 s, frame 9: 1.2 s, frame 15: 2 s).
3. Update `duration_s` for each voice in `audio_meta.json`, then run:
   `node ~/.claude/skills/product-launch-video/scripts/audio.mjs sync-durations --audio-meta ./audio_meta.json --storyboard ./STORYBOARD.md`
   followed by `node ~/.claude/skills/product-launch-video/scripts/assemble-index.mjs --storyboard ./STORYBOARD.md --hyperframes .`
4. Re-render. Keep the total under 2:00.

## Where the footage comes from

- Marketplace, bounties, wallet and composer: screenshots of the running app (Vite dev, 2× device scale).
- Mission page, provider comparison and the 3D workcell runs (`assets/rec-*-viewport.mp4`, `mission-*.jpg`): the real React UI, fed a mission plan generated by the repo's own `quote()` and selection code plus a simulated run with the real runtime and arm. The machine used for filming had no `ANTHROPIC_API_KEY`, so only Claude's decomposition step was written by hand (`/Users/rikhil/.claude/jobs/a373dc1b/tmp/mission/decomposition.json` at build time). For a fully live take, set the key and record a real mission.
- The person-walks-in moment (frame 8) is a motion-graphics overlay on real footage. The simulator doesn't render a person. The Lite vs Pro listings and prices are real catalog entries.
- Music: local MusicGen (`facebook/musicgen-small`), a 30 s seed crossfade-looped. SFX: the HyperFrames bundled library.
